GAMGUI 2.5 - Windows prebuilt

A point-and-click window for GAM7 (Google Workspace admin CLI). Extract the zip
and run GAMGUI\GAMGUI.exe. No install and no Python required. GAM7 itself must
already be set up on the machine.

New in 2.5
----------
- Dropdowns now use the words you see in the Google product, not the raw API
  value. Calendar sharing reads "See only free/busy (hide details)", "See all
  event details", "Make changes to events", "Make changes and manage sharing".
  Showing/hiding a calendar is Yes/No instead of true/false, and the calendar
  Color is a dropdown of Google's 24 named colors (Tomato, Blueberry, Sage ...).
  Vault "Data type" reads Gmail/Drive/Groups/Calendar/Chat/Voice, and matter
  State reads Open/Closed/Deleted.
- Closed the high-value gaps found by the built-in coverage audit. Now 304
  guided tasks across 29 categories (was 254 / 28):
  - Contacts: update a shared contact; list a user's personal contacts, "Other
    contacts", and contact groups; create/delete a contact group; list domain
    contacts (People API).
  - NEW "Cloud Identity Devices" category (the newer device API, separate from
    Mobile Devices): list devices and device users; approve/block a device
    user; wipe or cancel-wipe a device user or a whole device; delete a device;
    register a company-owned device by serial number.
  - Classroom: create a course; update course details; course info; sync
    teachers from a group; list coursework, announcements, topics, and student
    groups; remove a guardian link; cancel a pending guardian invitation.
  - Gmail: update/inspect a send-as identity; forwarding-address info, delete,
    and a whole-domain export (spot unexpected auto-forwarding).
  - Vault: create/list/inspect/delete saved search queries; count matching
    items before an export so you can size it first.

Also in the 2.x line
--------------------
- An "Extra arguments (advanced)" box on every task and a "Run ANY GAM command"
  console, so every remaining GAM7 command is reachable.
- OAuth Setup, dedicated Vault section, multi-domain dropdown, a "Bulk / Batch"
  category (run any command per CSV/Sheet row), and scoped Email Cleanup with a
  phishing incident-response workflow (including Drive attachment removal).
